# 阶段三：WhatsApp Web 建联与话术

## 1. 建联的操作序列

在 `web.whatsapp.com` 已登录的标签页里：

| 步骤 | 操作 | 判据 |
|---|---|---|
| 1 | `Ctrl+Alt+N` 打开「新聊天」面板 | 面板标题显示「新聊天」，搜索框提示「搜索姓名、电话号码或 @账号」 |
| 2 | 输入 E.164 格式号码（`+8615907510900`，不带空格和横线） | 面板下方出现「不在你的联系人中」+ 一个条目 |
| 3 | **看条目有没有头像/昵称** | 有头像或昵称 = 该号码注册了 WhatsApp；空白头像但有条目也算存在；**完全没有条目 = 未注册，停止** |
| 4 | 点击该条目 | 右侧打开会话，标题栏显示号码和「点击此处查看联系人信息」 |
| 5 | 点击底部「输入消息」框，粘贴文案 | 文案出现在输入框 |
| 6 | `Enter` 发送 | 消息出现在气泡中，带一个 ✓（已发送）；出现 ✓✓ 才是已送达 |

注意点：

- **不要用左侧聊天列表的搜索框建联**。那个框只搜已有会话和联系人，号码不在通讯录时不会给「新对话」入口，看起来像「号码不存在」，实际是走错了入口。必须走 `Ctrl+Alt+N` 的新聊天面板。
- 发送前**逐个核对会话标题里的号码**和目标号码一致。多点错一次就是发给了另一个人。
- 首次给陌生人发消息，会话里会出现一条黄色提示「消息和通话已进行端到端加密…」，属正常。

## 2. 验证账号存在性

三种结果：

| 现象 | 含义 | 动作 |
|---|---|---|
| 有条目、有头像 | 已注册且设置了头像 | 可以发 |
| 有条目、头像空白 | 已注册、没设头像 | 可以发 |
| 加载几秒后仍无任何条目 | 未注册 / 已注销 / 号码格式错 | 不发，记录为「无 WhatsApp」 |

空白头像不是「不存在」的证据，先等 2~3 秒再判。

## 3. 开场白怎么写

一条有效开场白必须同时做到三件事：

1. **说清从哪来的**（来源合法性，也是降低戒心的第一句）；
2. **给对方一个「为什么是你」的具体理由**（引用他评论里的原话或处境）；
3. **给一个低承诺的下一步**（不要一上来就要求长期绑定）。

### 三段式结构

```
[来源 + 呼应处境]  +  [我是谁 / 我的诉求]  +  [低门槛下一步 + 反问]
```

### 差异化规则（强制）

同一批次内，**至少改变三处中的两处**：

| 可变项 | 变体示例 |
|---|---|
| 切入点 | ①我也是新号 ②看到你说每天都在线 ③看到你留了号码 ④看到你贴了二维码 |
| 自我介绍 | ①做跨境的 ②手上有个新号 ③刚注册没多久 |
| 节奏提议 | ①固定早晚各一次 ②先试两三天 ③对方报时段 ④不着急慢慢来 |

### 实测有效的四种切入点

- **共情型**（对「新号不敢加人」这类）：先承认对方的顾虑，再给安全感。
- **对等型**（对「求搭子」）：强调我也是来找人互的，不是来推销的。
- **直接型**（对留了明文号码的人）：开门见山说就是看到你号码才加的，并为打扰致歉。
- **确认型**（对很久以前的帖子）：先问「你现在还在做这件事吗」，避免对方早已放弃。

### 反例（别写）

- 「你好，我们是XX公司，专业提供…」——营销味，直接进垃圾箱。
- 一次性群发同一段 100 字——平台上同一批人常互相认识，撞文案即暴露。
- 首条就发链接、二维码、价目表——最容易被风控标记的行为。

## 4. 跟进

对方回「可以」「好的」「111」这类，不要继续寒暄，**立刻把关系落成约定**：

```
好呀，那我们定个简单的节奏：我早上 8 点到 9 点、晚上 9 点到 10 点在线，
每天各发三五条、偶尔发条语音就行。你平时哪两个时间段方便？
```

追问「时段」而不是「要不要」，是把模糊意向变成可执行约定的关键一步。

## 5. 常见回复的处理

| 对方说 | 应对 |
|---|---|
| 「可以」/「好啊」 | 直接给时段模板，问他的时段 |
| 「你是干什么的」 | 一句带过真实业务方向，立刻把话题拉回互发节奏（不要展开推销） |
| 「加我微信吧」 | 先不加。跨平台导流是高风控动作，先把 WhatsApp 双向对话做起来 |
| 「要钱吗」 | 明确免费的互发，不涉及任何费用 |
| 长时间不回复 | 不要连发追问。48 小时后最多一条轻提醒，之后放弃 |

## 6. 会话命名

建联后建议在 WhatsApp 里给该会话加备注（联系人信息 → 添加昵称），格式 `互养-小鹿魚-小红书1012`。这样后续复盘时不需要回去翻小红书。
