# 阶段二：二维码解码与号码还原

评论区图片里的 WhatsApp 二维码有两种，能不能在网页端还原出手机号，取决于它编码的是哪种链接。

## 1. 先把图下载成原图

不要在屏幕上截图再解码——评论区的缩略图分辨率太低，倾斜和压缩会直接让解码失败。

正确操作：

1. 点击评论里的图片，进入全屏查看器；
2. 底部工具栏最右侧是下载按钮（形状是向下的箭头/托盘）；
3. 点击后文件落到系统下载目录，文件名形如：
   `<帖子标题>_1_<评论者昵称>_来自小红书网页版.jpg`

文件名里自带评论者昵称，这是把图片和评论人对应起来的最省事办法，别改名。

## 2. 解码

```bash
python scripts/decode_qr.py "/path/to/xxx_来自小红书网页版.jpg"
```

脚本会依次尝试：原图 → 灰度 → 灰度+Otsu 二值化 → 灰度放大 2 倍 → 放大 2 倍+锐化，直到解码成功。倾斜拍摄的手机截图通常在原图或灰度阶段就能出结果。

输出形如：

```
=== whatsapp找搭子养号_1_桃子队长_来自小红书网页版.jpg ===
  尺寸 1177x2560
  [原图/detectAndDecode] -> https://wa.me/message/45HQ7SRQGEXGN1?src=qr
```

## 3. 两种 payload 的区别（核心）

| payload 形态 | 来源 | 能否在网页端还原号码 | 处理方式 |
|---|---|---|---|
| `https://wa.me/message/<code>?src=qr` | WhatsApp **Business**（商业账户）分享的联系链接 | **能** | 打开链接 → 点「继续前往 WhatsApp 网页版」→ 自动建会话并显示真实号码 |
| `https://wa.me/qr/<code>` | 个人 WhatsApp 的「分享二维码」（Messenger 专用码） | **不能** | 网页打开只会提示「这段代码只适用于安装了 WhatsApp Messenger 的用户」，无号码可提取 |

判据很简单：**`/message/` 能救，`/qr/` 只能手机扫。**

`/qr/` 的本质是一次性令牌，不含手机号。要加这种人，只能用手机 WhatsApp → 新聊天 → 扫描。

## 4. `/message/` 链接的还原步骤

1. 浏览器新开标签页，访问该 `wa.me/message/...` 链接；
2. 页面会显示对方的**昵称 + 头像**（这就是身份核对点，先跟评论区昵称对上）；
3. 若弹出「此站点正在尝试打开 WhatsApp」的系统对话框，点**取消**；
4. 点页面上的「**继续前往 WhatsApp 网页版**」；
5. 会跳到 `web.whatsapp.com/send?phone=...` 并直接打开一个会话，**会话标题就是真实手机号**；
6. 记下号码，然后按 `whatsapp-web-ops.md` 发送开场白。

注意：链接打开的那一刻 WhatsApp 已经把这个会话建出来了，等于已经发生了「主动建联」。所以**一个链接只解析一次**，先想好话术再点，别反复开关。

## 5. 命令行探测（可选）

批量场景下想先判断链接是否有效，可以用 HEAD/GET 看状态码：

```powershell
foreach ($u in @('https://wa.me/message/XXX','https://wa.me/qr/YYY')) {
  try { $r = Invoke-WebRequest $u -MaximumRedirection 6 -UserAgent 'Mozilla/5.0 Chrome/128.0'
        "$u -> $([int]$r.StatusCode) $($r.BaseResponse.RequestMessage.RequestUri)" }
  catch { "$u -> $([int]$_.Exception.Response.StatusCode)" }
}
```

判读：

- `200` 且返回大段 HTML → 链接有效（值得用浏览器打开还原）；
- `400` → 该码已失效或被回收；
- `301/302` 且 Location 里带 `phone=` → 直接拿到号码。

注意 `wa.me/<纯号码>` 永远返回 200，所以**必须和一个已知无效的码做对照**，否则会把「页面存在」误判成「号码拿到了」。

## 6. 失败时的兜底

解码失败按顺序排查：

1. 图片是不是原图（大小 < 100KB 基本是缩略图，重下）；
2. 码面有没有被头像/贴纸遮住一角——遮住定位方块就无法解码，换下面中心区域重新裁切再试；
3. 该码是不是已经过期。个人 `/qr/` 码有效期短，隔天常失效；
4. 仍失败就明确告诉用户「这张码解不出来」，不要猜号码。
