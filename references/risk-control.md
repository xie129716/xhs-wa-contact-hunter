# 风控红线与节奏

这套流程的失败模式不是「拿不到线索」，而是**号被限制**。以下边界按「每账号每批次」计。

## 1. 数量上限

| 动作 | 安全值 | 危险线 |
|---|---|---|
| 单晚新建陌生会话 | ≤ 5 | > 8 |
| 单日新建陌生会话 | ≤ 8 | > 15 |
| 同一小时内发送陌生消息 | ≤ 2 | > 4 |
| 同一段文案连发 | 0（禁止） | 任何重复 |

达到 5 个就停手，不要「顺手再加一个」。这一条是基于平台对「短时间主动新建多个陌生会话」的判定逻辑，不是主观保守。

## 2. 账号层面的前置条件

新号（注册 < 30 天）的高危因素：

- 没有头像、没有简介、没有昵称 —— 会被直接判为营销号。
- 一注册就加陌生人 + 群发。
- 同一设备/同一 IP 上登录多个号。
- 号码来源是虚拟号（VoIP）而非实体 SIM。

动手前的自检清单：

- [ ] 头像、昵称、简介（About）都设置完整，且像真人
- [ ] 账号已静置至少 24 小时再开始加人
- [ ] 设备一机一号，IP 稳定不跳变
- [ ] 通讯录里已有 3~5 个正常老号（同事/朋友）作为锚点

## 3. 行为节奏

安全的模拟节奏：

1. **前一两天**：只和已有老号互发，建立正常对话基线；
2. **第三天后**：每天新增 1~2 个陌生会话，当天只发一条，不追问；
3. **有回复后**：优先把已有对话做深（来回 5 条以上），而不是继续加新人；
4. **任何时候**：不群发、不首条带链接、不在深夜集中发送。

## 4. 「互养」本身的连带风险

和陌生人互相养号，风险来自对方，而不只是你自己：

- 对方可能在互发几条后开始往你的会话里塞广告，把你也标记进同一网络；
- 一批互养的人如果设备/IP/行为高度同构，被判定时是**整批一起**处理；
- 有人专门以互养为名收集号码，转手做别的用途。

因此：

- 互养对象**宁少勿多**，3~5 个固定搭子远比 30 个松散联系人安全；
- 一旦对方开始发广告或拉群，立即停止互动并删除会话；
- 不要把自己的主号（有真实客户、有业务的号）放进互养池，单独用一个副号做这件事。

## 5. 数据与合规

- 每条线索保留**来源帖 URL + 评论时间 + 截图/原图**，这是「对方公开主动留联系方式」的唯一证明。
- 只处理**公开发布**且**主动求联系**的线索。评论区里被动提及的第三方号码不要用。
- 对方明确表示不感兴趣后，从台账里标记 `拒绝`，不再触达。

## 6. 触发风控后的表现与处理

常见信号（按出现顺序）：

1. 发送后长时间只有一个 ✓，永远不变 ✓✓；
2. 给陌生人发消息时提示「无法发送」；
3. 账号被要求重新验证手机号；
4. 提示「此账号似乎违反了服务条款」。

处理：

- 出现第 1 条：当天停止所有外发，只回复已有对话；
- 出现第 2 条：停止 24~48 小时，期间只用老号互发；
- 出现第 3、4 条：立即停用该号，不要试图反复验证，越试越糟。

**不要在被限制后立刻换号继续同一批线索**——线索是共享的，换号等于把新号也送进去。
