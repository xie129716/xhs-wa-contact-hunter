# 开场白话术骨架

原则：**一条消息里同时完成「说清来源」「给出具体理由」「给出低承诺的下一步」三件事**，并且同批次内必须差异化。

差异化检查表（发每一条前过一遍）：

- [ ] 切入点和他评论里的原话对得上吗？
- [ ] 自我介绍和前一条不一样吗？
- [ ] 节奏提议和前一条不一样吗？
- [ ] 有没有出现链接、二维码、价格、公司名？（有就删）

---

## 骨架 A：共情型

> 适用：对方表达过顾虑（「新号不敢加人」「怕被封」「不敢群发」）。

```
你好呀～我是从小红书过来的，看到你说〔引用他的顾虑原话〕，我完全理解，我这边也是刚注册没多久。
要不我们互相加一下？每天早晚各发几句、偶尔发个语音，慢慢把号养起来就好，
不用着急，先聊几天看看节奏合不合适。
```

## 骨架 B：对等型

> 适用：对方在公开「求搭子」「求互养」，姿态是对等的。

```
你好～翻到你之前求〔搭子/互养〕的留言，不知道现在还缺人吗？
我手上有一个新号想慢慢养起来，不想一上来就群发。
如果你也在找稳定的搭子，我们可以互相加一下，每天随手聊几句就好，不勉强。
我这边时间比较灵活，你说个大概时段？
```

## 骨架 C：直接型

> 适用：对方在评论里直接留了明文号码。

```
你好！看到你留号码说想一起〔养号/互加〕，我就直接加了，希望没打扰到你。
我这边是新注册的号，想找几个固定的号每天互发消息增加活跃度。
如果你还有在找搭子，我们可以先聊聊彼此的节奏和习惯，合适的话就长期一起。你那边现在方便吗？
```

## 骨架 D：确认型

> 适用：帖子或评论是几天前甚至几个月前的，对方可能已经不在做这件事。

```
你好～看到你之前在小红书留了两个号码说互加，我这边也在养新号，想找固定的搭子互相发消息。
先问一下，你现在还有在〔养号/做这个〕吗？
如果有的话我们加一下，每天互发几句、慢慢来就好，不着急也不勉强。我这边基本全天在线。
```

## 把意向落成约定的追问

对方回「可以」「好啊」之后，不要继续寒暄，直接给模板问时段：

```
好呀，那我们定个简单的节奏：
我早上 8 点到 9 点、晚上 9 点到 10 点在线，每天各发三五条、偶尔发条语音就行。
你平时哪两个时间段方便？
```

提问用「哪两个时段」而不是「要不要」，是把模糊意向变成可执行约定的关键。

---

## 常见回复的应对

| 对方说 | 应对 |
|---|---|
| 「可以」/「好啊」/「111」 | 直接上时段模板 |
| 「你是干什么的」 | 一句带过真实业务方向，立刻把话题拉回互发节奏，不展开推销 |
| 「加我微信吧」 | 先不加，先把 WhatsApp 双向对话做起来（跨平台导流是高风控动作） |
| 「要钱吗」 | 明确是免费的互发，不涉及任何费用 |
| 「我号很多」 | 警惕，可能是批量操作者，会被一起判定；降低接触频率 |
| 长时间不回复 | 不要连发追问，48 小时后最多一条轻提醒，之后放弃 |

## 反例清单

| 别写 | 原因 |
|---|---|
| 「你好，我们是 XX 公司，专业提供…」 | 营销味，直接进垃圾箱 |
| 同一段 100 字群发 | 这批人常互相认识，撞文案即暴露 |
| 首条就发链接 / 二维码 / 价目表 | 最容易被风控标记 |
| 「在吗」 | 零信息量，容易被忽略 |
| 一上来就问「你有多少粉丝」「能带货吗」 | 对方是来找搭子的，不是来接商单的 |
